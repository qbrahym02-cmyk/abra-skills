# video-publishing — الرفع آخر خطوة صناعة، وأول خطوة توزيع

القاعدة الصادقة: **أداة رفع مباشرة مدمجة غير موجودة**. النشر يتم عبر (1) مسارات حقيقية مهيأة عند المستخدم: YouTube Data API / TikTok Content Posting API / Buffer — تحتاج كلها مفاتيح وموافقات يستخرجها المستخدم بنفسه، أو (2) خوادم MCP يضيفها في Settings → mcpServers فتصبح أدوات الوكيل، أو (3) الجاهزية الكاملة: الملفات + الميتاداتا جاهزة للرفع اليدوي في دقيقتين. دورك الافتراضي: الطريق الثالث كاملاً ثم أبلغ عن المتاح فعلاً من الأول والثاني.

## متى تحمّل هذه المهارة
«انشر الفيديو» · «جهّز للنشر» · «اكتب وصف وعنوان الفيديو» · «جدوِل المنشورات».

## حزمة النشر (سلّمها كاملة دائماً)
اكتب ملف `publish-<slug>.md` في المشروع:

    المنصة: <youtube/tiktok/instagram>
    الملف النهائي: montage-output/<الملف> (اجتاز montage_qc)
    المصغرة: montage-output/<الصورة>
    العنوان: ≤60 حرفاً — فضول + كلمة مفتاحية، بلا clickbait كاذب
    الوصف: سطران أولان يحملان القيمة (قبل «اعرض المزيد») ثم الفصول:
      00:00 الفصل … (روابط الفصول تعمل في YouTube)
    الوسوم/الهاشتاغات: 3–5 دقيقة (الأولى الأهم) — من بحث الترند لا التخمين
    نص أول تعليق (pin): سؤال يفتح نقاشاً أو رابط الأداة
    أفضل وقت نشر: <تقديرك مع سببه>

## الميتاداتا — القواعد
- العنوان: وعد محدد لا عام — «3 قصات تجعل الفيديو أسرع» لا «نصائح مونتاج».
- أول 125 حرفاً من الوصف تظهر قبل القص — ضمّن القيمة والكلمة المفتاحية فيها.
- الفصول (YouTube): زمن ‏00:00 إلزامي + 3 فصول على الأقل حتى تظهر.
- الهاشتاغ في العنوان: واحد فقط كحد أقصى (خوارزمية تيك توك تفضّل الوصف/النص).
- لغة الميتاداتا = لغة الجمهور المستهدف لا لغة صانع الفيديو إن اختلفتا.

## مسارات الرفع (تحقق ثم تحدث)
- **mcp_status**: خوادم MCP المهيأة عند المستخدم (يفيد لو أضاف خادم نشر). إن وُجد: استعمل أدواته (mcp_<server>_<tool>) — هذا الطريق الرسمي لوكلاء خارجية النشر في أبرا.
- **الموصلات** (connectors): إن كان للمستخدم موصل ذو صلة فاستعمله؛ إن لا: لا تدّعِ.
- **API مباشر بrun_command/http_request**: ممكن تقنياً للمستخدم المطوّر الذي زوّدك مفاتيحه في .env — عندئذ ارفع عبر YouTube Data API v3 (upload → set metadata) بصرامة: مفتاح المستخدم مسؤوليته، لا تخزّنه في ملفات المشروع.
- الافتراضي الصادق: «الملفات والميتاداتا جاهزة — الرفع دقيقتان يدوياً؛ إن أردت رفعاً آلياً هيّئ خادم MCP للنشر أو مفاتيح API وسأستعملها».

## الجدولة
- أوقات الذروة تختلف بالجمهور — تقديرك يُعلن كتقدير، والمصدر الحقيقي بيانات قناة المستخدم (مهارة video-analytics بعد أول أسبوعين).
- scheduler الروتينات المحلي (schedule_create) يفتح النافذة/يذكّر لا يرفع للمنصات — قل ذلك بصدق.
- سلسلة أسبوعية بنفس الموعد تبني عادة مشاهدة أفضل من التفريق العشوائي.

## آداب
- لا تنشر باسم المستخدم عبر أي مسار دون إذن صريح في هذه المهمة.
- حقوق الموسيقى/المادة: آخر سؤال قبل الرفع («المصدر مرخّص للنشر؟») — سؤال واحد يقي حظراً.
- بعد النشر: افتح الصفحة (browser_open) وتحقق بصرياً أن المصغرة والعنوان سليما العرض — أخطاء العرض بعد الرفع شائعة ومكشوفة.
